# ZEE 的个人名片网页

这是我在 Vibe Coding 课程中完成的第一个作品——一个像素风格的个人名片网页。整个网页只有一个 index.html 文件，双击就能打开，不需要联网，也不依赖任何外部图片和字体。

## 项目介绍

我喜欢像素游戏的感觉，所以这次做了一个星露谷风格的个人名片。页面是横向布局，左边是一个用纯 CSS 画出来的像素小人（黑色卷发、穿黑色长裙的女生），右边是我的昵称、介绍、兴趣标签和联系方式。

背景是一片天空，白天有太阳和飞鸟，云朵会慢慢向右飘；到了晚上切换成月亮和闪烁的星星，整个天空和卡片都会变成深色系。我想让这个页面看起来像一张游戏角色卡，所以还加了等级条和血条。

## 如何运行

把项目下载到本地，双击 index.html，用浏览器打开就行了。不需要安装任何东西，不需要启动服务器，也不需要联网。手机浏览器打开也能正常看，布局会自动变成上下排列。

## 已完成功能

根据 index.html 的实际内容，这个页面目前做到了以下功能：

- 像素人物：用纯 CSS 的 box-shadow 画了一个 12 列 14 行的像素小人，黑色卷发、黑色长裙，日间和夜间模式下人物的肤色、腮红等会跟着变色。
- 状态徽章：人物上方有一个钉钉风格的状态标签，日间显示「学习中...」，夜间自动变成「休息中...」，旁边有绿色小圆点在闪烁。
- 等级条和血条：人物下方有一条等级条显示 LV 18 和经验进度，再下面是四条像素游戏风格的血条，分别是精力、耐心、好奇、能量，每条颜色不同，带有分段刻度线。
- 个人信息：右侧展示了昵称 ZEE、一句话介绍「用山川湖海填满自己的心脏」、三个兴趣标签（自然摄影、音乐欣赏、策略游戏）。
- 邮箱复制：展示了邮箱地址 3491538690@qq.com，旁边有一个复制按钮，点击后会把邮箱复制到剪贴板，按钮会短暂显示「已复制」，用了 Clipboard API 并兼容了不支持的环境。
- 日夜模式切换：点击按钮可以在日间和夜间之间切换，页面所有颜色、天空、太阳/月亮、飞鸟/星星都会跟着变化，按钮文字也会变。
- 天空背景和动态元素：背景是天空渐变色，有六朵不同大小的像素云朵向右飘动。日间右上角有像素太阳（带射线和光晕）和五只像素飞鸟（翅膀会扇动，不同高度和速度）；夜间切换为像素月亮（带陨石坑）和三十颗闪烁的星星。
- 响应式：屏幕宽度小于 680px 时卡片自动变成上下排列，小于 380px 时像素人物会缩小，不会出现横向滚动。
- 像素风视觉：整个页面用等宽字体、硬边框、偏移硬阴影、steps() 分步动画来营造复古游戏卡带的质感，主色是粉青色。
- 图片轮播：点击「自然摄影」标签会弹出全屏图片轮播弹窗，展示自然图片文件夹中的 19 张照片；点击「音乐欣赏」标签会展示音乐文件夹中的 8 张照片。弹窗支持左右箭头切换、键盘方向键翻页、点击空白处或按 ESC 关闭，底部显示当前页码和总数量。

## 我的探索

我尝试让 AI 帮我修改页面风格，将一开始的简约风换成像素风。又让其帮我生成个人像素人物和等级条，并对动态页面背景进行了大量的修改，添加飞鸟云朵，太阳等新元素，调试日夜切换时元素的更改。
